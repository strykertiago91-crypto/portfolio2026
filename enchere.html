Fonctionnalités
Ce que fait l'application
🔐
Authentification sécurisée
Connexion par email / mot de passe hashé (bcrypt). Filtre de session protégeant toutes les routes privées. Redirection automatique selon le rôle.
🏷️
Enchères en temps réel
Règle de mise : montant minimum = enchère la plus haute + 0,10 €, ou 0,20 € si aucune enchère. Validation côté serveur pour éviter la triche.
📊
Statistiques
Tableau de bord secrétaire : nombre de ventes, enchères totales, acheteurs actifs, articles les plus populaires.
📱
Génération de QR codes
La secrétaire peut générer un QR code pour chaque vente afin de partager facilement son URL.
✉️
Emails groupés
Envoi automatique d'emails aux inscrits : ouverture de vente, rappel, annonce des résultats et gagnants.
📄
Export PDF
Export PDF d'une vente complète avec la liste des participants, enchères et résultats finaux.

Controllers/Secretaire.php 
class Secretaire extends BaseController
{
    public function index()
    {
        $modVente = new ModeleVente();
        $donnees['lesVentes'] =
            $modVente->getLesVentes();

        echo view('header');
        echo view('vue_secretaire', $donnees);
        echo view('footer');
    }

    public function creer_vente()
    {
        $modVente = new ModeleVente();
        $nomVente   = $this->request->getPost('nom');
        $dateDebut  = $this->request->getPost('debut');
        $dateFin    = $this->request->getPost('fin');

        $modVente->creerVente(
            $nomVente, $dateDebut, $dateFin
        );
        return redirect()->to('/secretaire');
    }
}
Controllers/Habitant.php — miser() 
public function miser()
{
    $modEnchere  = new ModeleEnchere();
    $idVetement = $this->request->getPost('id_vetement');
    $montant    = $this->request->getPost('montant');
    $idUser     = session()->get('id_user');

    // Calcul montant minimum requis
    $best = $modEnchere->getPrixMax($idVetement);
    $min  = $best
        ? $best['montant'] + 0.10
        : 0.20;

    if ($montant < $min) {
        return redirect()->back()
            ->with('error', 'Montant trop bas');
    }

    $modEnchere->ajouterEnchere(
        $idVetement, $montant, $idUser
    );
    return redirect()->to('/habitant');
}

CREATE TABLE enchere (
  id_enchere  INT AUTO_INCREMENT PRIMARY KEY,
  id_vetement INT NOT NULL,
  montant     DECIMAL(8,2) NOT NULL,
  id_user     INT NOT NULL,
  date_heure  DATETIME DEFAULT NOW(),
  confirme    TINYINT DEFAULT 0,
  FOREIGN KEY (id_vetement)
    REFERENCES vetement(id_vetement),
  FOREIGN KEY (id_user)
    REFERENCES utilisateur(id_user)
) ENGINE=InnoDB;

Filters/FiltreConnexion.php 
class FiltreConnexion implements FilterInterface
{
    public function before($request, $args = null)
    {
        // Vérifie si l'utilisateur est connecté
        if (!session()->get('connecte')) {
            return redirect()->to('/');
        }

        // Vérifie le rôle si spécifié en argument
        if (!empty($args)) {
            $role = session()->get('id_role');
            if (!in_array($role, $args)) {
                return redirect()->to('/');
            }
        }
    }
}
