Le projet
Epi-Solidaire

Application web développée en PHP permettant de gérer une épicerie solidaire. Les employés se connectent avec leur compte et accèdent aux fonctionnalités selon leur rôle.

🔑
Connexion
Chaque employé se connecte avec son identifiant. L'accès aux pages dépend de son rôle.
🏪
Gestion des commerces
Consulter, ajouter ou supprimer les commerces partenaires de l'épicerie.
👥
Gestion des acheteurs
Gérer la liste des habitants inscrits à l'épicerie solidaire.

Contexte

La commune de Getcet-sur-Mer dispose d'une épicerie solidaire pour les habitants à faibles revenus. L'application permet de gérer les commerces partenaires et les acheteurs inscrits.

Organisation

Le site est développé en PHP avec une architecture MVC. Les pages s'affichent dynamiquement selon le rôle de l'employé connecté.

Accès sécurisé

Chaque employé se connecte avec son identifiant. Selon son rôle, il accède à des fonctionnalités différentes. Les pages non autorisées sont bloquées.

controleurs/c_gererCommerces.php 
<?php
include("vues/v_sommaire.php");
$action = $_REQUEST['action'];

switch($action) {
    case 'gererCommerces':
        $lesCommerces = $pdo->getLesCommerces();
        include("vues/v_listeCommerces.php");
        include("vues/v_ajoutCommerce.php");
        break;

    case 'ajouterUnCommerce':
        $nom   = $_REQUEST['nom'];
        $rue   = $_REQUEST['rue'];
        $cp    = $_REQUEST['cp'];
        $ville = $_REQUEST['ville'];
        $pdo->ajouterUnCommerce($nom,$rue,$cp,$ville);
        $lesCommerces = $pdo->getLesCommerces();
        include("vues/v_listeCommerces.php");
        break;

    case 'supprimerCommerce':
        $pdo->supprimerCommerce($_REQUEST['id']);
        $lesCommerces = $pdo->getLesCommerces();
        include("vues/v_listeCommerces.php");
        break;
}
Sql/getcet.sql — Extrait schéma 
-- Table commerce
CREATE TABLE commerce (
    id         int NOT NULL AUTO_INCREMENT,
    nom        varchar(50),
    rue        varchar(100),
    codePostal VARCHAR(5),
    ville      varchar(50),
    PRIMARY KEY (id)
) ENGINE=InnoDB;

-- Table acheteur
CREATE TABLE acheteur (
    id         int NOT NULL AUTO_INCREMENT,
    idHabitant int NOT NULL,
    idFoyer    int NOT NULL,
    PRIMARY KEY (id),
    FOREIGN KEY (idHabitant, idFoyer)
        REFERENCES habitant(idHabitant, idFoyer)
) ENGINE=InnoDB;

-- Table vendre (prix solidaire)
CREATE TABLE vendre (
    idCommerce    int,
    refProduit    varchar(5),
    prixOrigine   DECIMAL(5,2),
    prixSolidaire DECIMAL(5,2),
    PRIMARY KEY (idCommerce, refProduit, dateJour)
);
